# Contributing to NiftyDesign

NiftyDesign is an unofficial alpha based on DesignCraft by the ArtCraft team. It is not supported by ArtCraft or Microsoft.

## Report an issue

1. Read [KNOWN-LIMITATIONS.md](docs/KNOWN-LIMITATIONS.md) first. Listed items are already known.
2. Open an issue at https://github.com/srt8hellcat2-ui/niftydesign/issues and pick a form: **Bug report** or **A file failed to open**. **Never report to the ArtCraft repositories or community.**
3. Give: the NiftyDesign version, your Windows version, what you did, what happened, and the exact warning or error text (open errors start with "import:").
4. **Do NOT attach a file that contains names, addresses, phone numbers, emails, financial details or photos of people.** A screenshot is fine only if it has none of those.
5. Do not attach your `.pub` at first. The maintainer will ask if one is needed. Then offer it privately, not in a public issue.

## Donating sample `.pub` files

Files from real Publisher users are the most useful test material. Safe checklist:

- [ ] The file is yours to share.
- [ ] It contains nothing private: no names, addresses, phone numbers, emails, financial details, or photos of people who have not agreed. If part is private, remove it from a **copy**, or leave the file out.
- [ ] You tell the maintainer which Publisher version made it (if you know) and what the file is for (bulletin, flyer, calendar, brochure, newsletter, file with tables or WordArt).
- [ ] You send it only after the maintainer asks, by the private channel they give you. `[owner fills in: contact method]`
- [ ] You know it is used only to check that opening, editing, saving and PDF export work, is kept out of the public repository, and will be deleted if you ask. This is the proposed intake policy; the maintainer must settle the contact method before requesting files.
