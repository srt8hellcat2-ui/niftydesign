# Contributing to NiftyDesign

NiftyDesign is an unofficial alpha based on DesignCraft by the ArtCraft team. It is not supported by ArtCraft or Microsoft.

## Report an issue

1. Read [KNOWN-LIMITATIONS.md](docs/KNOWN-LIMITATIONS.md) first. Listed items are already known.
2. Open an issue at https://github.com/srt8hellcat2-ui/niftydesign/issues and pick a form: **Bug report** or **A file failed to open**. **Never report to the ArtCraft repositories or community.**
3. Give: the NiftyDesign version, your Windows version, what you did, what happened, and the exact warning or error text (open errors start with "import:").
4. **Issues are public.** Do NOT attach anything that contains names, addresses, phone numbers, emails, financial details or photos of people. A screenshot is fine only if it has none of those.
5. You do not need to attach your file. The warning text and what you see are usually enough. Attach a `.pub` only if it is safe for the whole internet to see.

## Donating sample `.pub` files

Real files from Publisher users are the most useful test material. Because issues are public, attach a file only if all of these are true:

- [ ] The file is yours to share.
- [ ] It contains nothing private: no names, addresses, phone numbers, emails, financial details, or photos of people who have not agreed. If part is private, remove it from a **copy**, or leave the file out.
- [ ] You tell us which Publisher version made it (if you know) and what the file is for (bulletin, flyer, calendar, brochure, newsletter, file with tables or WordArt).
- [ ] You are happy for it to be public. An attachment on an issue can be seen by everyone. If you want it kept private, do not attach it: describe what it contains instead, or open an issue saying you have one you cannot share.
- [ ] You understand how it is used: only to check that opening, editing, saving and PDF export work. It will not be added to the repository, and the attachment will be removed from the issue if you ask.

A PDF exported from Publisher of the same file is a big help. It shows how the page is meant to look.

## Code

The source is in this repository. Small, focused pull requests are welcome: one problem per pull request, with a test, and no code copied from any other `.pub` reader. The importer is clean-room; read docs/CLEANROOM.md first. If a fix belongs in shared DesignCraft code, it may also be offered upstream to ArtCraft. Please do not open issues or pull requests with ArtCraft on the maintainer's behalf.
